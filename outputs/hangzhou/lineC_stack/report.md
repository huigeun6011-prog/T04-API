# 항저우 C선 2019-01-08 shift-and-stack 시간표 맞춤 시험

**결론: 사전 기준(양끝 2역 이내 ≥60%)은 미통과(45.33%), 관측 역 1~2개 조각 ≤5%는 통과(0.00%). 둘 다 통과해야 하므로 관문은 미통과다. 기준·설정은 결과를 보고 바꾸지 않았다.** 다만 기존 방법의 핵심 실패(조각 53%)는 사라졌고, 숨긴 역 보류 평가는 재현율 82.3%(랜덤 이동 대조 31.2%)였다. 이 시간표는 태그에서 뽑은 추정이며 공식 시간표가 아니다. 1/15는 열지 않았다.

## 방법 (scripts/hangzhou/lineC_stack.py, 그림은 lineC_stack_figures.py)
1. 기존 C선 직접 통행 방향 앵커(`direct_directions`)로 하차 태그에 방향 부여. 방향 미지정은 기여하지 않음. 역 31개(54 제외, 선로상 54는 구간시간만 유지하고 이벤트 미발행).
2. 구간 운행시간 초깃값: 기존 `initial_intervals`(같은 방향·같은 OD, 30건 이상, Q25 가중 최소제곱) 그대로. 누적 운행시간 합이 종점까지 약 4,480~4,510초.
3. 역·방향별 하차 1초 히스토그램 → σ10초 평활 → 해당 시각 전후 30분 평균(기준선)으로 나눈 비(상한 6, 기준선 바닥 0.001/초)를 z로 사용. 열차 기준 시각 T0(출발 종점 도착)마다 `z_k(T0 + 누적운행시간_k + 보행 30초)`를 모든 역에 대해 평균(shift-and-stack). 평균 신호에서 피크: 간격 ≥60초, 높이 ≥ 전후 30분 평균의 1.8배(실행 전 고정).
4. 조정: 역별 누적 운행시간 보정 adj_k를 3회 반복으로 추정(각 역의 신호가 현재 열차 기준 시각들과 가장 겹치는 지연, ±45초 탐색, 역별 누적 보정 한도 ±60초). 실제 보정량 최대 46초(66번 방향)·60초(34번 방향, 한도 도달 1역). 정차시간·보행 30초는 고정(구간시간에 흡수). 이 조정과 열차 기준 시각이 모두 같은 날 태그에 맞춰진 것이므로 **같은 날 내부 일관성이며 독립 검증이 아니다.**
5. 도착시각 = T0 + 누적시간 + adj. 하루 안에 모든 역 도착이 들어오지 않는 열차는 제외(5개). 관측 근거 = 기존 `find_daily_peaks`가 낸 해당 역·방향 피크의 도착 후보가 ±45초 안에 있음.
6. 보류: 환승·종점 제외 내부 역 29개 중 3개마다 1개(3분할 3회)를 숨김. 숨긴 역은 쌓기·보정에서 제외하고 adj는 이웃 역에서 선형보간. 숨긴 역의 실제 피크 대비 재현율, 같은 시각을 ±120~600초 랜덤 이동한 대조군(200회) 비교.
7. 대조(귀무) 평가: 역마다 신호와 피크를 독립적으로 원형 이동(±900~3000초)시킨 뒤 같은 파이프라인으로 열차를 만들어 우연 수준의 관측 역 수를 측정(3회).

## 수치 (양방향 합산, 2019-01-08)
| 항목 | 기존(피크 연결, 관측 기준) | 새 방법(shift-and-stack) | 귀무(역별 이동) 3회 | 기준 | 판정 |
|---|---:|---:|---:|---:|---|
| 열차 후보 수 | 1,200 | 439 (66방향 223, 34방향 216) | 359 / 311 / 357 | - | - |
| 양끝 종점 2역 이내 | 17.42% | **45.33%** | 36.2 / 41.5 / 24.6% | ≥60% | 미통과 |
| 관측 역 1~2개 조각 | 53.00% | **0.00%** | 3.1 / 6.4 / 4.2% | ≤5% | 통과 |
| 관측 역 수 중앙값 | 2 | 27 (31개 중) | 14~17 | - | - |
| 관측 역 20개 이상 열차 | - | 82.2% | 15~25% | - | - |

- 방향별 양끝 2역 이내: 66번 방향 40.81%, 34번 방향 50.00%. 둘 다 조각 0%.
- 민감도(참고만, 주 설정 유지): 쌓기 높이 1.5배 → 453개·44.81%·조각 0%, 2.5배 → 389개·50.13%·조각 0%. 어느 설정도 60%에 못 미친다.
- 미통과 원인(진단): 열차마다 끝역 근처 관측이 모자란다. 출발 종점에서는 그 방향 하차가 없고(관측 0%), 66번 방향의 35·36번은 관측 비율 13%·41%, 34번 방향의 65·64번은 19%·47%다(방향 앵커가 적은 역). '시작·끝 관측이 종점 2역 이내' 정의가 이 구조에서는 열차가 끊겼는지와 상관없이 낮게 나온다. 중간 역 대부분의 관측 비율은 66번 방향 70~93%, 34번 방향 65~92%다. 이 해석은 진단이며 기준을 바꾸지 않았다.
- 귀무가 완전히 낮지 않다(양끝 25~41%, 관측 역 14~17개): 피크가 빽빽해(방향당 열차 간격 약 290초, ±45초 창이면 우연 적중 약 31%) 우연 적중이 높다. 새 방법 값은 귀무보다 분명히 높으나 지표 자체의 변별력이 낮다는 뜻이다.

## 열차 기준 시각 간격(배차 규칙성)
- 방향별 간격 중앙값 66번 283.5초(사분위 255~305), 34번 289초(265~312). 변동계수 0.27/0.41. 120초 미만 3.6%/5.1%, 600초 초과 0.9%/0.5%.
- 시간대 중앙값: 7~8시 약 180~220초(피크), 9~16시 약 280~295초, 17시 215~235초, 21시 이후 363~469초. 05시·06시·22시 대는 표본이 적어 불안정. 단축·회차가 있으면 흐려질 수 있으나 큰 구멍은 보이지 않았다(미확인: 실제 운행 편수와의 비교).

## 한계
- 같은 날 태그로 기준 시각·역별 보정을 맞추고 같은 태그의 피크로 평가한 내부 일관성이다. 독립 정답이 아니다. 열차 후보 439개는 운행 편수가 아니다.
- 이 시간표를 쓰는 이후 같은 태그의 OD 역산은 순환(유리한 편향) 위험이 있다.
- 새 방법은 정의상 모든 열차가 전 역에 걸쳐 정의되므로, '관측 역 수'는 기존과 같은 의미가 아니다(열차 구조를 가정한 뒤 관측을 센 값). 조각 0%는 이 구조의 결과일 수 있고, 실제 회차·단축운행은 이 방법으로 잡히지 않는다(관측 역 10개 미만 열차는 약 1.4%뿐이라 분포에서 구분되지 않는다).
- 보행 30초·정차시간은 공통 가정. 54번 역은 이벤트 미발행. 앵커가 적은 종점 근처 역은 근거가 약하다.
- 기준 높이(1.8배)·보정 한도(±60초)·z 상한 등은 사전 고정이며 조정은 민감도에 한정했다.
