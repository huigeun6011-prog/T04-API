# lineC_final 주말 그룹 기준 (실행 전 고정)

입력 날짜만 바꾸고 pool2·pool3 규칙·상수는 평일과 한 글자도 다르지 않다(코드 `lineC_pool2.py`, `lineC_pool3.py`의 함수를 그대로 호출). 입력 날짜: 주말 1/05, 06, 12, 13, 19, 20 + 1/01(날짜 점검에서 주말 시간표와 같다고 나옴, M 중앙값 0.89). 평일 그룹과 별도로 구성.

- 운행 시간대 05:00~23:30, 쌓기 절대 하한 1.0, 풀링 기준선 바닥 = 1e-3 × 날 수(7), 단측 계획 시각 15분위(짝이 날 수의 절반 이상 = 4일), 규칙성 보간, 역별 랙(5분위, 수축 200).
- pool3 채우기: 기대 열차 수는 **주말 입력으로** E1 절차(lineC_struct와 같음: 독립 피크, 푸아송 대조 8회, 정보 칸 n_tr ≥ 8 이고 초과 ≥ 0.5, 역 위치 4~27 중앙값, 정보 칸 3개 미만이면 채우지 않음)를 새로 계산한다. 채움 조건·상한(≤ 0.85×기대일 때, min(기대−N, 40%N), ≤ 1.05×기대, 공백 ≥ 1.3×H, 쌓기 하한 1.2배 기준선·절대 1.0)은 평일과 같다.
- 평가: 평일과 같은 정의(배정 가능, 음수, 창 안, 방향 일치; 랙 30/0과 랙 맞춤), 열차 수, 양끝 2역 이내, 1~2역 조각, 07~22시 최대 공백, 시간대별 평균 배차 간격과 두 방향 비, 시간별 배정 가능. pool2 재생성 대비 pool3.
- 진단 보류일 1/12: 풀링·계획 시각·랙 맞춤에서 제외(기대 열차 수는 7일 E1 그대로, 약한 누수).
- 주말에는 E3/E2 단축 진단을 하지 않는다. 최종 파일 `candidate_arrival_events_final_weekend.csv`는 평일 파일과 같은 열이고 `low_signal`·`structure_status`는 '미확인', `refuted_share_cell`은 비움. group = weekend.
