# Stage B0: where do cross-line passengers change lines? (2019-01-08 only; A/B/C not mapped to real lines)
Scripts: scripts/hangzhou/stageB0_prepare.py -> stageB0_hubs.py -> stageB0_via_extra.py (run in order, python -I). Metrics, classes and the hold-out recipe are declared in the script headers, written before results; nothing was tuned. Assumptions throughout: station position = rank of stationID in its block (ID-order hypothesis), one constant walk+wait W per hub, no branches resolved, hubs are (station on X, station on Y) pairs because each line has its own IDs.

## Short answer
- Interchanges are only partly identifiable. **A-C is clear**: one hub explains the data (A id 77 with C id 46, W = +7.2 min, 88% of 68,030 trips within +-5 min, mean |residual| 2.8 min); the nearest alternatives are the neighbouring stations (A78, C47), so the hub is known to +-1 station. **B-C is ambiguous**: B id 10 is stable, but the C side lies somewhere in C47-C51 (best C48, W = +4.0, 60% within 5 min, mean |res| 5.5). **A-B is not explained by one hub**: best is A79 (the A end) with B6, but W is negative (-5.7 min), only 43% within 5 min and the top candidates span B0-B8; a second hub (A79-B12) cuts held-out error by 46% but then it looks like a mixture, not a single clean interchange.
- Share of the 396,394 cross-line trips that can be split into legs with a single hub within +-5 min: **59%** (A-B 43%, A-C 88%, B-C 60%). Allowing two hubs per pair raises the within-5 share to 80% but only **36%** remain unambiguously assigned (second-best hub >= 3 min worse), because the second hubs are neighbours of the first (AC: C46/C47, A77/A78).
- Hold-out (random half of users): top-1 hub agrees within +-1 station for all three pairs and per-trip assignment agreement is 99.9-100%. This checks sampling stability on one day, not structural truth.

## Details
- Same-line leg model (q25 by |position difference|, intercept removed): about 2.4-2.8 min per station and a 2.4-2.8 min constant per line (A 2.79 and 2.43, B 2.51 and 2.79, C 2.41 and 2.58). One anomalous adjacent pair: B id 27-28 (q25 30 min vs 5.2 median, n=81), possible gap or branch; not resolved.
- Geometry: trips funnel through the hub from both sides on A-C (A side below/at/above hub 61/13/26%, C side 26/17/57%); for A-B the A hub sits at the line end (X_below 97%), as expected for a terminal-side interchange.
- Direction consistency: both travel directions of each pair give the same residual (AB 5.9 vs 5.9 min, AC 2.1 vs 2.0, BC 3.9 vs 4.0), i.e. the symmetric hub model is not contradicted.
- Weak consistency check (taps at hub stations vs +-3 neighbours): A-C hubs high (C46 1.68x, 97th percentile; A77 1.37x), B10 0.99x, C48 0.80x, A79/B6 0.42x/0.37x (low). Supports A-C only; it is not independent evidence.
- Third-line routes (post-hoc): A->C via B fits worse than direct (mean |res| 4.5 vs 2.8; only 6% of trips better via B vs 25% better direct). C via A for B-C fits worse (9.2 vs 5.5). A-B via C is about equal (7.4 vs 6.9; 32% of trips better via, 37% better direct) and not better than the 2-hub direct fit; all via fits need negative W, i.e. they are not physically plausible. So double transfers are not indicated for A-C or B-C; for A-B the data cannot say.
## Not checked
