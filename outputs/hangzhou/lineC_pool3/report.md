# lineC_pool3: 놓친 열차 채우기 (평일 18일)

작성: 메인 세션(2026-11-18). 수치는 항저우 에이전트의 보고와 `docs/EXPERIMENTS.md` E-28 기준이며, 이 문서 작성 중 스크립트를 다시 실행하지 않았다. 세부 판정 기준은 같은 폴더의 `criteria.md`.

## 방법

- pool2(평일 풀링 시간표)에서 방향×시간대별 열차 수가 기대보다 모자란 곳에 열차를 추가한다.
- 기대 열차 수 = `lineC_struct`의 E1(역별 독립 하차 피크 간격 중앙값)에서 구함, 정보 칸 3개 이상일 때만.
- 채우는 조건(고정): pool2 열차 수가 기대의 85% 이하. 추가 수 = min(기대−N, 40%×N), 채운 뒤 105% 초과 금지.
- 위치: 쌓기 신호가 문턱 아래(1.2배 기준선, 절대 1.0 이상)인 최고 후보. 모두 `imputed`(`relaxed_stack`)로 표시.

## 결과

| 항목 | pool2 | pool3 |
|---|---:|---:|
| 열차 후보 수 | 430 | 440 |
| 양끝 2역 이내 | 85.1% | 83.9% |
| 1~2역 조각 | 0.2% | 0.2% |
| 배정 가능 | 100% | 100% |
| 창 안 | 92.9% | 93.1% |
| 방향 일치 | 67.9% | 66.9% |
| 34번 방향 07~22시 최대 간격 | 529초 | 424초 |

- 34번 방향 07–09시 평균 배차 353→252초(66번 방향 246초), 34/66 비 1.43→1.02.
- 새로 채운 열차 10개(34번 방향 07–09시 8개, 66번 방향 19–23:30시 2개). pool2의 10개와 합쳐 `imputed` 20개.
- 진단 보류일 1/16: 창 안 92.7%, 방향 일치 66.3%, 배정 가능 100%. 외우기 징후 없음.

## 한계

- 기대 열차 수가 같은 태그의 독립 피크 간격이라, 피크 누락이 있으면 기대가 낮게 나온다.
- 1/16 보류에서도 E1 기대값은 18일 값을 그대로 써 약한 누수가 있다.
- 채운 열차는 쌓기 신호의 낮은 문턱 후보라 실제 열차라는 확정이 아니다.
- 05–07시와 34번 방향 19–23:30시는 E1 기대값이 없어 채우지 못했다. 66번 방향 19–23:30시는 후보 부족으로 일부(2/10)만 채웠다.
- 방향 일치가 1%p 낮아졌다.
