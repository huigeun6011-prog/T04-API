# 판정 기준 (실행 전 고정, 결과를 보고 바꾸지 않는다)

날짜 2019-01-08 하루만. 1/15는 열지 않는다. 대상은 `outputs/hangzhou/lineC_stack/candidate_arrival_events_stack.csv`의 시간표(이하 (a))와 같은 설정으로 만든 엄격 시간표((b)).

## 0. 사실 확인(판정 아님)
`lineC_stack.py`는 `direct_directions`의 앵커(입장·출장 모두 C 게이트 코드, 서로 다른 역)만 쓴다. C 출장 태그 전체 대비 앵커 비율, 제외 사유별 개수(짝 없음 / 입장이 A·B / 같은 역 / 시차 밖)를 센다.

## 1. 승객 실행가능성(입장 태그 = 시간표 생성에 쓰이지 않은 정보)
승객: 앵커 통행(입장·출장 모두 C, 시차 0 초과 180분 이하). 입장 시각 E = 출장 시각 X − 소요시간.
- 배정: 승객 방향 d의 열차 중 출장 역 x 도착 A_x ≤ X − 30초(보행지연, 시간표 생성과 동일 값)인 가장 가까운 선행 열차. X−30−A_x가 600초 초과면 배정 불가.
- 입장 역 e 출발 D = A_e + 30초(정차시간 근사). 대기시간 w = D − E.
- 방향 일치율: 방향 구분 없이 양방향 열차 중 가장 가까운 선행 열차를 고를 때 그 열차 방향 = 승객 방향인 비율.
- 시간대(출장 시각): 출퇴근 7~9시·17~19시, 낮 9~17시, 저녁 19~24시, 이른 아침 5~7시(참고용).
- 지표: 배정 가능 비율, 음수 대기(w<0) 비율, 창 내 비율(0≤w≤600초), 분위수(5·25·50·75·95), 방향 일치율.
기준 시간표 (a)의 통과 조건(전체 승객, 방향 지정 배정):
- P1 배정 가능 ≥ 90%
- P2 음수 대기 ≤ 10%
- P3 창 내 비율 ≥ 75%
- P4 방향 일치율 ≥ 70%
- P5 시간대(출퇴근·낮·저녁, 승객 1000명 이상인 대역) 각각 음수 대기 ≤ 15%
- P6 대조 대비: 비이동 대조(방향 뒤바꿈, 열차 국소 섞기, 무작위 시간표, 역별 독립 원형 이동)마다 (대조의 음수 비율 − (a)의 음수 비율) ≥ 10%p 이고 ((a)의 창 내 비율 − 대조의 창 내 비율) ≥ 10%p. 방향 일치율은 방향 뒤바꿈·무작위 시간표·역별 원형 이동 대조에 대해 (a)가 10%p 이상 높아야 한다. 확률 대조는 3회 평균.
전부 충족해야 통과. 하나라도 못 미치면 미통과.

대조 시간표 정의(모두 (a)의 열차 도착 행렬 기반):
- 전체 이동 ±30·60·90·120초: 모든 열차·역 도착에 같은 값을 더함. **참고 보고만, 통과 조건에 넣지 않는다.** 이유(사전 명시): 입장 역 출발 D가 같이 늦어지면 음수 대기 비율은 구조적으로 줄어들어 이 지표로 이동을 가려낼 수 없다. 대신 q05·q25 위치 이동을 같이 보고한다.
- 방향 뒤바꿈: toward_66 열차 행렬과 toward_34 행렬의 방향 이름을 서로 바꿈.
- 열차 국소 섞기: 방향마다, 역마다 시간순 열차를 연속 5개 블록으로 묶어 블록 안 순서를 무작위 치환(역 사이 연결만 흐트러뜨림).
- 무작위 시간표: 방향마다 열차 기준 시각을 같은 개수만큼 하루 범위에서 균등 무작위로 뽑고 (a)의 역별 누적 오프셋을 그대로 더함.
- 역별 독립 원형 이동: 역마다 열차 도착을 ±(900~3000)초 중 무작위 값으로 이동(E-23 귀무와 동일 크기).
무작위 대조 시드 20190108.

## 2. 환승 제외 엄격 비교
(b) 엄격 앵커 = (a) 앵커 중 입장·출장 역 모두 TR 집합에 없는 통행. TR(환승·환승 후보) = {C 선로에서 `transfers[(C,A)]`·`transfers[(C,B)]`에 나오는 C측 역 ID} ∪ {소속 2개 이상 역} ∪ {C 역 중 POI 역명이 A 또는 B 노드의 역명과 같은 역}. 54번은 태그가 없어 영향 없음.
(b)는 `lineC_stack.py`의 함수·상수(1.8배, 보정 ±60초, 보행 30초 등)를 그대로 쓰고 앵커만 바꾼다.
비교 항목: 열차 후보 수, 양끝 2역 이내·1~2역 조각 비율, 관측 근거 역 수(관측 피크 ±45초 확인된 열차-역 칸 수와 하나라도 관측 있는 역 수), 하차 앵커 수, 1)의 지표(공통 승객 = 입장·출장 모두 TR 밖인 승객으로 두 시간표 모두 평가), 보류 평가(숨긴 역 재현율: 숨김 후보는 E-23과 같은 내부·비공유·비54 역에서 TR 밖인 역만, 각 시간표는 자기 앵커로 만든 피크와 비교, 랜덤 ±120~600초 이동 대조 200회).
판정 규칙: (b)가 (a)보다 '낫다' = 공통 승객 P2(음수)·P3(창 내) 모두 2%p 이상 개선, 그리고 공통 숨김 역 재현율이 1%p 이상 낮아지지 않음. '나쁘다' = P2·P3 모두 2%p 이상 악화 또는 재현율 1%p 초과 하락. 그 외 '뚜렷한 차이 없음'. 결과를 있는 그대로 적는다.
