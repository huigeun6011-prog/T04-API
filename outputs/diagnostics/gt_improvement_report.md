# GT 배분 및 투명성 개선 실험

## 실행 범위와 배포 상태

- 서비스일 2024-11-01~2026-11-01, 마지막 실제 시각 2026-11-02 00시.
- 731일, 171,142열차, 3,733,691개 정차 표본을 candidate_training에 별도 생성했다.
- production `outputs/ground_truth_train_loads.csv`, `load_predictor.joblib`, `model_metrics.json`은 교체하지 않았다. CSV와 모델 SHA256이 기존 metadata와 일치함을 확인했다.
- 실제 피크 CSV의 인원수는 목적함수·학습 타깃·solver 선택·가중치에 사용하지 않았다. 레시피를 고정한 후 19개 매칭 사례를 사후 검증했다.

## 변경한 방법

### 배분 가능한 방향의 지지집합

종점 승차·출발점 하차를 제외한 실제 정차 수를 사용한다. 양방향 모두 가능하면 기존 sigmoid 분배율을 유지하고, 한쪽만 가능하면 그쪽에 관측 인원 전부를 배분한다. 양쪽 모두 불가능하면 관측값을 변경하지 않고 명시적 unallocated 행으로 남긴다. 이전 코드는 불가능한 방향에도 분배율을 부여해 실제 열차에 배분되지 않은 인원이 조용히 사라졌다.

### soft 목적함수 유지

출발 승차 전 인원은 0으로 시작한다. 종점 인원 0과 음수 누적 인원 억제는 기존과 같이 제곱 soft penalty다. 비율이 식별 가능한 양방향 셀에만 지리 prior를 적용한다. Adam 학습률 0.1, 최대 1000회, 유의 개선이 100회 정체하면 중단하고 관측한 최저 손실 iterate를 복원한다. 전체 731일은 모두 1000회까지 실행했고 best epoch는 973~1000회였다. 정확한 수렴이나 물리 제약 충족을 보장하지 않는다.

### 원시 궤적과 비음수 투영 구분

- `raw_load`: 반올림 전 승차-하차를 열차 시작부터 누적한 값. 종점도 덮어쓰지 않는다.
- `load`: 학습 입력을 위한 `max(raw_load, 0)` 투영값. 종점을 임의로 0으로 덮어쓰지 않는다.
- `load_correction`: `load-raw_load`. 음수 투영의 크기를 명시한다.
- `terminal_raw_residual`: 종점 정차의 원시 잔여 인원.
- `*.diagnostics.jsonl`: 일자별 손실·원시 음수·종점 잔여·투영량.
- `*.unallocated.csv`: 시간표에 배분 가능한 승차/하차 정차가 전혀 없는 관측 셀.

원시 궤적의 산술 보존이 맞아도 raw_load는 soft 목적함수 때문에 음수일 수 있다. 투영된 load는 학습용 근사 타깃이며 board/alight와 물리적으로 일치하는 정답이라고 주장할 수 없다.

## 대표일 비교

개편 전후 평일·휴일, 일반 평일, 전체 원본 총량 감사에서 발견한 자정 이상 가능일을 고정해 비교했다. 실제 피크 인원수로 날짜나 파라미터를 선택하지 않았다.

`gt_improvement_comparison.json/csv`에는 기존 200/1000회와 개선 200/1000회, 개선 초기값 seed 11/29의 결과가 있다. 정상 5일은 개선1000에서 기존200보다 원시 종점 MSE가 감소했고 설명되지 않던 미배분도 제거됐다.

2025-08-14는 기존 미배분 승차 약4058명이 명시 slack 98명으로 줄면서 정규 시간표에 추가 배분된 인원이 드러났다. 종점 MSE는 약688에서 44,481로 커졌다. 인원을 몰래 버려 얻었던 작은 잔차와 직접 비교해 solver가 나빠졌다고 판단할 수는 없으나, 시간표와 관측 집계의 불일치 가능성을 해결한 결과도 아니다.

## 전체 자료 검증 결과

- raw 보존식 `raw_i = raw_previous + board - alight`: 허용 0.0000016명에서 위반0행, 최대오차 약0.000001명.
- `load=raw_load+load_correction`: 위반0행.
- 출발 전0·출발점 하차0·종점 승차0, 비유한값 없음, board/alight/load 비음수 검사 통과.
- 각 321,640개 역시간셀에서 배분+slack=원본: 허용0.001명 위반0셀.
- 승차 원본73,500,080명, 배분73,497,363.997673명, 명시slack2,716명(538셀). 미설명오차 최대0.000305명.
- 하차 원본73,217,641명, 배분73,202,457.009877명, 명시slack15,184명(1,375셀). 미설명오차 최대0.000181명.
- 원시 음수105,609행(−0.015명 미만), 최솟값−775.310614명.
- 음수 투영105,704행, 투영 총량1,522,835.319374명.
- 종점 잔여 절댓값 중앙값10.392명,95%44.877명,99%74.736명,최대3127.189명.
- 가장 큰 잔여 일자는 2025-08-07~14에 집중된다. 연장운행 등의 정규표 불일치 가능성은 가설이며 원본 측정 정의를 확인하지 못했다.

세부 결과는 candidate_training/physical_validation.json에 있다.

## candidate 모델과 외부 피크 사후 검증

- 날짜 순서 학습584일/검증147일: MAE21.94명,RMSE31.80명,R²0.8593.
- 이 수치는 수정된 추정 라벨에 대한 점수다. 기존 MAE20.14와 타깃 정의가 달라 단순 우열을 말할 수 없다.
- 배포 후보 파일은 전체731일로 refit했지만 production에는 교체하지 않았다.
- 외부 실제 피크20건 중 시간표 매칭19건: candidate 모델MAE374.45명, 추정라벨MAE324.88명. 기존 모델375.99명 대비 실제 피크 예측이 유의하게 좋아졌다고 볼 결과는 아니다.
- 외부 피크 표본은 선택된 극단 사례이고 측정 시점/정의가 불명확하며, 날짜도 refit 학습 범위에 들어간다. 독립 holdout 일반 정확도로 해석하지 않는다.

## 판단

가능한 방향으로 배분하고 불가능한 관측량을 명시하는 개선과 원시 잔차 보존은 유효하다. 그러나 자정의 큰 불일치와 실제 피크 정확도가 해결되지 않았고, 개선 후보가 실제 재차인원 예측에서 충분히 검증됐다고 판단할 근거가 없다. candidate만 보존하고 기존 production 모델을 유지한다.
