## F-001: 시각별 승하차인원을 열차에 균등분배

- 상세: 승차인원을 각 열차에 임의로 균등하게 분배한 후 결과를 확인함.
- 결과: 종점 재차 상행 평균 +26.81 (절대평균 35.06), 하행 평균 -23.76 (절대평균 42.75)
- 원인: 상하행 구분 없이 비현실적으로 일괄 1/n 값이 분배됨.
- 개선안: 유사 연구 사례나 논문을 참고하여 방법론을 탐구.

## F-002: 기존 사례 참고

- 상세: 승차인원을 각 열차에 배정하는 방법론에 대해 기존의 사례를 찾아봄.
- 결과
  -- 1. Fluid Analogy Method: 논문 계산방식 공개되지 않음. 계산방식이 공개되더라도 양방향 사례에 적용할 수도 없음.
  -- 2. Modeling the Origin-Destination Matrix with Incomplete Information: 시간대 정보가 무시됨. 실측값으로 검증되지 않은 계산법.
- 개선안: 손실함수와 제약조건을 직접 설정.
