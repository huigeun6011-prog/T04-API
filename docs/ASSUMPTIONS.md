## A-002: 시간대별 승하차인원 열차 내 분배 방법

(사용자 작성 초안에 AI가 2026-11-16 빈 항목을 보완했다. 보완한 내용은 코드와 진단 보고서에 근거한 사실만 적었다.)

- 가정
  -- 1. 역·시간별 승하차 합계는 방향 구분이 없다. 이를 상행/하행 몫(p, q)으로 나눈 뒤, 같은 역·같은 시간·같은 방향에 정차하는 열차끼리 동일하게 분배한다. (몫 p, q는 역·시간별로 최적화한다. 열차 간 균등 분배는 최적화 대상이 아니라 고정된 가정이다.)
  -- 2. 출발점 승차 전 열차 내 인원은 0명이다.
  -- 3. 종점 도착 후 열차 내 인원은 0명이다. (구현은 soft penalty이며 정확히 만족한다고 보장하지 않는다.)
  -- 4. 모든 승하차 인원은 음수가 아니다. (재차인원의 음수도 soft penalty로 억제한다.)
- 반영: `scripts/data_prep/generate_ground_truth.py`(production은 이전 solver `outputs/diagnostics/gt_solver_before_improvement.py`). 승차는 `p*B/n_trains`, 하차는 `q*A/n_trains`.
- 근거: 열차별 승하차 실측이 없고 역·시간별 집계만 있어, 열차 사이를 구분할 정보가 없다.
- 한계
  -- 1. 열차별 편차를 만들지 못한다. 같은 역·시간·방향의 열차는 승차 인원이 모두 같다.
  -- 2. 실제 피크 열차(604~717명)는 균등 배분 기준(방향 50:50, 하차 무시)의 1.20~2.58배(평균 1.88)였고, 추정 라벨은 실제의 0.42~0.61배(평균 0.53)였다. 진단 전용 결과이며 [feasibility_bound 보고서](../outputs/diagnostics/feasibility_bound/report.md)와 [ROADMAP](../ROADMAP.md)의 완료 기록을 따른다.
  -- 3. 방향 몫 p, q는 실제 통행 방향을 측정한 값이 아니다.
- 영향: 추정 라벨과 이를 학습한 production 모델이 평균 열차 수준에 머문다. 이 가정을 완화하는 후보로 승차 headway(`--boarding-headway`)가 구현돼 있으나 production에는 적용하지 않았고, 대기열·정원 모델은 실험 결과 효과가 없어 폐기를 권고했다(상세는 ROADMAP).
