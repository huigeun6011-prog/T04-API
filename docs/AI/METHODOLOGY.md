# 대전도시철도 1호선 열차 재차인원 추정 및 예측 방법론

본 문서는 **"특정 날짜·역·시간대·방향·날씨 조건에서, 열차 내 승객 수(재차인원, Load)를 예측하는 모델"**을 구축하기 위해 채택된 전체 방법론, 수학적 최적화 로직, 손실함수의 세부 수식, 데이터 흐름, 그리고 최종 모델의 사용법을 상세히 기술합니다.

---

## 1. 문제 정의 및 해결 과제

### 1.1 대전 1호선 노선 특성

- **노선 구조**: 단일 노선, 22개 역 (101 판암 $\leftrightarrow$ 122 반석).
- **운행 방향**:
  - **상행**: 반석 $\to$ 판암 (서쪽 외곽 $\to$ 둔산 도심 $\to$ 원도심/동쪽 외곽)
  - **하행**: 판암 $\to$ 반석 (동쪽 외곽 $\to$ 원도심 $\to$ 둔산 도심 $\to$ 서쪽 외곽)
- **주요 도심**: 대전역·중앙로(구도심 상업/교통), 시청·정부청사(둔산 신도심 업무/행정 지구).

### 1.2 핵심 난제 (Why is it hard?)

1. **정답(Ground Truth)의 부재**: 열차별 실제 승하차 센서 데이터나 재차인원 실측치가 존재하지 않음.
2. **방향 정보 부재**: 개찰구 승하차 카운트는 역별 1시간 단위 총합만 제공되며, 승객이 상행선을 탔는지 하행선을 탔는지 구분되지 않음.
3. **엄격한 물리적 보존 법칙**:
   - 출발역 승차 전 재차 = $0$
   - 종점 도착 후 하차 완료 시 잔류 재차 = $0$
   - 열차 내 재차인원은 항상 비음수 ($Load \ge 0$)
   - 이전 역 재차 + 이번 역 승차 - 이번 역 하차 = 이번 역 통과 재차인원 ($L_s = L_{s-1} + b_s - a_s$)

## 2. 방법론 선정 배경 및 대안 비교

본 프로젝트는 **"2단계 하이브리드 파이프라인 (탄력적 수치 최적화 $\to$ 지도학습 머신러닝)"**을 채택하였습니다.

```
[1단계: 과거 정답 복원] ──(물리 제약 유도)──> [물리적 재차인원 라벨 생성]
                                                       │
[2단계: 미래 예측 모델] <──(특성-라벨 지도학습)─────────┘
        │
        ▼
[3단계: 실시간 미래 추론 (입력: 조건 → 출력: 재차인원)]
```

### 타 방법론과의 비교 및 채택 이유

| 방법론                                   | 원리 및 한계                                                                                                                                                                          | 채택 여부 및 평가 |
| :--------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------: |
| **단순 균등 분배 (`F-001`)**             | 시간대별 총승하차를 통과 열차 수($1/n$)로 분배. 상하행 출퇴근 비대칭을 무시하여 **종점 잔류 인원이 상행 $+26.8$명, 하행 $-23.8$명으로 물리적 파탄** 발생.                             |      ❌ 기각      |
| **단일 종단간 딥러닝 (`PINN`)**          | 신경망 하나로 물리 손실을 주입하여 학습. 무작위 배치 셔플링 시 1개 열차의 22개 정차역이 끊겨 종점 재차 계산이 불가능하며, 수렴이 매우 불안정.                                         |      ❌ 기각      |
| **하드 제약 수리최적화 (LP/QP)**         | 완벽한 0을 강제하는 하드 제약 최적화. 현실 데이터의 미세한 계수 불일치나 시각표 지연으로 인해 **해 없음(Infeasible)** 에러 발생 위험 높음.                                            |      ❌ 기각      |
| **탄력적 수치최적화 + GBDT (본 방법론)** | 1단계에서 물리 제약을 목적함수(Loss)로 두어 **종점 오차를 $\approx 0$으로 유도**하고 정답 데이터를 복원한 뒤, 2단계에서 고속 GBDT로 일반화 학습. 안정성, 정확도, 추론 속도 모두 최적. | **✅ 최종 채택**  |

## 3. 1단계: 탄력적 수치 최적화 (Ground Truth 복원)

과거 데이터의 개찰구 승하차 총량을 바탕으로, 상/하행 분배율을 역산하여 열차별 물리적 재차인원을 복원하는 단계입니다.

### 3.1 핵심 가정 (Assumptions)

1. **열차별 균등 분담**: 동일 시간대, 동일 역을 통과하는 같은 방향의 열차들은 해당 방향 승하차 인원을 균등하게 나누어 태운다.
2. **단말역 경계 조건**: 기점에서는 하차 인원이 $0$이고, 종점에서는 승차 인원이 $0$이다.
3. **승객 보존 법칙**: 승객은 허공에서 생기거나 사라지지 않으며, 열차가 종점에 도착하면 모든 승객이 하차하여 잔류 재차는 $0$에 수렴해야 한다.
4. **비음수성**: 열차 내 승객 수는 음수가 될 수 없다 ($Load \ge 0$).

### 3.2 참조 데이터 파일

- `./data/processed/subway/{날짜}.json`: 역별·시간대별(5~23시) 총승차($B$), 총하차($A$).
- `./data/processed/subway/{익일날짜}.json`: 익일 00시 승하차 기록을 당일 24시 막차 지연 하차 버킷으로 귀속.
- `./data/processed/subway_time/subway_time_20250930.json`, `subway_time_20260330.json`: 열차별 정차역, 통과 시각, 상/하행 방향.
  - _주의_: 2026-03-30 이후라도 '휴일'인 날은 20250930의 휴일 시간표를 폴백으로 사용.
- _(참고: 날씨 데이터는 1단계 최적화 연산에는 사용되지 않으며, 최적화 완료 후 2단계 학습을 위한 결과 테이블에 결합(Join)됩니다.)_

### 3.3 최적화 알고리즘

- **알고리즘**: PyTorch 기반 `Adam (Adaptive Moment Estimation)` (학습률 $0.1$, 200 에포크).
- **결정 변수 (Parameters)**:
  - $p_{\text{logits}} \in \mathbb{R}^{20 \times 20}$: 중간 20개 역, 20개 시간대(5~24시)의 상행 승차 비율 로짓 ($p = \sigma(p_{\text{logits}})$)
  - $q_{\text{logits}} \in \mathbb{R}^{20 \times 20}$: 중간 20개 역, 20개 시간대(5~24시)의 상행 하차 비율 로짓 ($q = \sigma(q_{\text{logits}})$)
  - (판암역은 $p=0, q=1$ 고정, 반석역은 $p=1, q=0$ 고정)

### 3.4 손실함수 (Loss Function) 상세

$$\mathcal{L} = \mathcal{L}_{\text{terminal}} + 1.0 \times \mathcal{L}_{\text{negative}} + 2.0 \times \mathcal{L}_{\text{prior}}$$

#### ① 종점 재차 최소화 손실 ($\mathcal{L}_{\text{terminal}}$)

$$\mathcal{L}_{\text{terminal}} = \frac{1}{N} \sum_{k=1}^{N} \left( \text{Terminal\_Load}_k \right)^2$$

- **$N$**: 해당 일자 하루 동안 운행한 총 열차 수 (평일 약 242대).
- **목적**: 242대 모든 열차가 종점에 도착했을 때 남은 승객이 $0$이 되도록 강제.

#### ② 음수 재차 방지 페널티 ($\mathcal{L}_{\text{negative}}$)

$$\mathcal{L}_{\text{negative}} = \frac{1}{M} \sum_{k=1}^{N} \sum_{s=1}^{S_k} \left( \text{ReLU}(-\text{Load}_{k,s}) \right)^2$$

- **$M$**: 하루 전체 열차의 총 정차 횟수 (약 5,281회 정차 시점).
- **왜 $-\text{Load}$와 $\text{ReLU}$인가?**:
  - $\text{ReLU}(x) = \max(0, x)$이므로, 양수 승객($Load > 0$)일 때는 $-Load < 0$이 되어 페널티가 $0$이 됨.
  - 오직 승객 수가 음수($Load < 0$)로 떨어지는 물리적 오류가 발생할 때만 $-Load > 0$이 되어 그 크기만큼 제곱 벌점을 부과함.

#### ③ 지리적 사전 가이드 손실 ($\mathcal{L}_{\text{prior}}$)

$$\mathcal{L}_{\text{prior}} = \frac{1}{S \times H}\sum_{s=1}^{S}\sum_{h=1}^{H} \left( p_{s,h} - p_s^{\text{prior}} \right)^2 + \frac{1}{S \times H}\sum_{s=1}^{S}\sum_{h=1}^{H} \left( q_{s,h} - q_s^{\text{prior}} \right)^2$$

- **사전 기준값**:
  $$p_s^{\text{prior}} = \frac{s}{21}, \quad q_s^{\text{prior}} = 1 - \frac{s}{21} \quad (s: 0\text{ 판암} \sim 21\text{ 반석})$$
- **역할**: 선형 기하학적 초기값을 앵커(Anchor)로 두어, 분배율이 상식적인 지리적 경향을 벗어나 역전되거나 극단값($0$ 또는 $1$)으로 요동치는 오버피팅을 방지.

## 4. 2단계: 미래 예측 머신러닝 모델 학습

1단계에서 생성된 물리적 정답 라벨(`load`)을 지도학습하여, 개찰구 승하차 카운트가 없는 미래 시점의 열차 재차인원을 즉각 추론하는 모델을 만듭니다.

### 4.1 알고리즘 선정: `HistGradientBoostingRegressor`

- **선정 이유**:
  - LightGBM 호환 아키텍처로, 범주형 및 수치형 변수가 혼합된 정형(Tabular) 데이터에서 신경망 대비 뛰어난 정확도 제공.
  - 출퇴근 피크 시간대(08시, 18시) 및 도심 혼잡역(시청, 대전역)의 극단적인 비선형 패턴을 완벽히 포착.
  - 추론 속도가 마이크로초($\mu s$) 단위로 극도로 빠름.

### 4.2 피처 및 타깃 정의

- **입력 피처 ($X$)**:
  1. `station_idx`: 정차역 고유 인덱스 ($0 \sim 21$) - _Categorical_
  2. `hour`: 운행 시간대 ($5 \sim 24$) - _Numerical_
  3. `dir_code`: 상행($0$) / 하행($1$) - _Categorical_
  4. `is_weekend`: 평일($0$) / 주말 및 법정공휴일($1$) - _Categorical_
  5. `temp`: 기온 ($^\circ\text{C}$) - _Numerical_
  6. `precip`: 강수량 ($\text{mm}$) - _Numerical_
  7. `snow`: 적설량 ($\text{cm}$) - _Numerical_
  8. `plan_version`: 2026-03-30 시각표 개편 버전 ($0$ 또는 $1$) - _Categorical_
- **타깃 ($y$)**: 열차 내 재차인원 (`load`)

### 4.3 2단계 손실함수의 필요성

$$\text{MSE} = \frac{1}{K}\sum_{i=1}^{K} (y_i - \hat{y}_i)^2$$

- 2단계의 손실함수는 **머신러닝 모델의 채점 기준표(Objective)**입니다.
- 모델이 세운 수백 개의 의사결정 나무(Decision Tree)가 예측한 값($\hat{y}$)과 1단계 정답($y$)의 오차를 측정하여, 오차가 최소화되는 방향으로 트리의 분기 조건과 가중치를 학습시킵니다.

### 4.4 검증 성능

- **시간 순 분할 검증 (Out-of-Time Validation)**:
  - Train: $46,473$건 $\to$ $\text{MAE } 10.74\text{명}, \quad R^2 = 0.9653$
  - Validation (미래 3일): $15,315$건 $\to$ $\text{MAE } 25.62\text{명}, \quad R^2 = 0.8396$
- **기점/종점**: 판암 $\text{MAE } 3.6\text{명}$, 반석 $\text{MAE } 7.1\text{명}$ (매우 정밀)
- **혼잡 도심역**: 시청, 대전역 등의 출퇴근 통근량 대규모 흐름을 안정적으로 재현.

## 5. 3단계: 실시간 미래 추론 인터페이스 및 사용법

### 5.1 추론 프로그램: `predict_load.py`

사용자로부터 미래 시점의 조건을 입력받아 즉시 예상 재차인원과 혼잡도를 반환합니다.

#### 입력 파라미터 (Inputs)

| 인자명        | 필수 여부 |     형식     | 설명                                                        |
| :------------ | :-------: | :----------: | :---------------------------------------------------------- |
| `--station`   | **필수**  |    문자열    | 대전 1호선 22개 역명 중 하나 (예: `시청`, `대전`, `반석`)   |
| `--hour`      | **필수**  |     정수     | `5` ~ `24` (24는 자정 넘김 막차)                            |
| `--direction` | **필수**  |    문자열    | `상행` 또는 `하행`                                          |
| `--date`      |   선택    | `YYYY-MM-DD` | 기준 날짜 (미입력 시 오늘 날짜). 요일, 법정공휴일 자동 판정 |
| `--temp`      |   선택    |     실수     | 예상 기온 (기본값: `15.0` $^\circ\text{C}$)                 |
| `--precip`    |   선택    |     실수     | 예상 강수량 (기본값: `0.0` $\text{mm}$)                     |
| `--snow`      |   선택    |     실수     | 예상 적설량 (기본값: `0.0` $\text{cm}$)                     |

#### 출력 데이터 (Outputs)

- **예상 열차 재차인원 (명)**: 해당 열차 내 탑승 승객 수
- **혼잡도 등급**: 대전 1호선 4량 1편성(정원 약 450명) 기준 분류
  - `여유 (좌석 여유)`: 80명 미만
  - `보통 (착석 가능 또는 일부 입석)`: 80 ~ 180명
  - `약간 혼잡 (입석 다수)`: 180 ~ 300명
  - `혼잡 (손잡이 유지)`: 300 ~ 450명
  - `매우 혼잡`: 450명 이상

## 6. 결론 및 향후 확장 방안

1. **물리적 일관성과 예측력의 분리 해결**: 정답이 없는 역문제를 수치최적화(1단계)로 선결하고 머신러닝(2단계)으로 일반화함으로써, 물리적 파탄 없이 현실적인 미래 재차인원 추론기를 성공적으로 구축했습니다.
2. **Prior 고도화 가능성**: 현재의 선형 거리 Prior($s/21$)를 향후 도심(시청/정부청사) 인력 기반의 시간대별 비선형 함수로 확장하면 출퇴근 시간대 정밀도를 추가로 향상시킬 수 있습니다.
