📋 API 데이터 수집 작업 안내

1. 작업 목표
   공공데이터포털의 대전교통공사 API를 호출하여, 지정된 기간(2026년 10월 1일까지)의 모든 데이터를 1일 단위로 수집하고, 응답받은 원본(XML)을 하위 디렉토리에 파일로 저장하는 작업을 수행해 주세요.

2. API 정보
   Base URL: https://apis.data.go.kr/B554695/TicketTypeTrafficSVC

오퍼레이션: getTicketTypeTraffic01

응답 포맷: XML

인증 방식: 공공데이터포털 발급 인증키(serviceKey) 사용

3. 요청 방식 (매우 중요)
   ⚠️ 반드시 지켜야 할 사항
   1일 단위 요청: startDate와 endDate를 동일한 날짜(YYYYMMDD) 로 설정하여, 하루씩 요청해야 합니다.

수집 기간: 2026년 10월 1일(20261001)까지 데이터를 수집합니다. (시작일은 20261031)

요청 URL 예시: https://apis.data.go.kr/B554695/TicketTypeTrafficSVC/getTicketTypeTraffic01?serviceKey={비밀키}&startDate=20261001&endDate=20261001&pageNo=1

4. 저장 방식
   저장 위치: 프로젝트 내 하위 디렉토리를 생성하여 저장해 주세요. (예: ./data/raw/20261001.xml/)

파일명: 날짜로 저장해 주세요. (예: 20261001.xml)

형식: API 응답 원본(XML)을 가공하지 않고 그대로 저장해 주세요.

5. 작업 절차 요약
   수집할 날짜 범위를 설정합니다. (2026-10-01 ~ 2026-10-31)

날짜별로 반복문을 실행합니다.

각 날짜에 대해 pageNo를 1부터 시작하여 totalCount에 도달할 때까지 반복 요청합니다.

응답받은 XML 원본을 하위 디렉토리에 저장합니다.

모든 날짜와 페이지에 대한 수집이 완료될 때까지 반복합니다.

6. 주의사항
   API 호출 간 충분한 대기 시간(sleep)을 두어 서버에 부담을 주지 않도록 해주세요. (예: 요청 간 0.1~0.5초 대기)

인증키(serviceKey)는 환경변수나 별도 설정 파일에서 불러오도록 하여, 코드에 직접 노출되지 않도록 해주세요.

응답의 resultCode가 00(정상)인지 확인하고, 오류 발생 시 로그를 남겨주세요.
