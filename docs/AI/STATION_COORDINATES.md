# 대전 1호선 역 좌표

## 출처와 기준

- 기준일: 2026-11-16
- 좌표계: WGS84 (latitude, longitude)
- 검색 출처: VWorld 검색 API 2.0의 장소 검색 (`type=PLACE`), 역명으로 조회
- 선택 기준: 역명 일치, 대전 권역, 지하철역 분류를 우선 확인했다. 동일 역 중복 POI는 해당 역으로 분류된 결과 좌표를 평균해 마커가 역사 중심에 놓이도록 했다.
- 대전역은 VWorld에서 `지하철역` 세부 분류가 아닌 일반 철도시설 POI로 검색되어, 대전광역시 동구 정동의 대전역 POI를 사용했다.
- 공식 VWorld 검색 API 예제: [VWorld 공식 API 예제 저장소](https://github.com/V-world/V-world_API_sample/blob/master/%5B%EA%B2%80%EC%83%89API%5D%20%EB%A7%88%EC%BB%A4%20%EB%8B%AB%EA%B8%B0%20%EC%9D%B4%EB%B2%A4%ED%8A%B8.html)

현재 화면의 이전 수기 좌표와 비교하면 일부 역에서 약 1.9km까지 차이가 났다. 수정 좌표는 `web/app.js`의 `STATIONS`에서 지도 마커와 가장 가까운 역 계산에 함께 쓰인다. 역 순서와 `idx`는 예측 모델의 역 인덱스와 맞추어 그대로 유지했다.

## 검토 메모

`web/app.js`의 `STATIONS` 22개 값은 이 표와 일치한다(2026-11-16 문자열 대조). 사용자가 지도가 표시되는 것은 확인했으나, 마커가 실제 역사 위치와 맞는지는 별도로 검증하지 않았다. 필요하면 지도에서 역사 중심과 마커를 대조해야 한다. VWorld 장소 좌표는 역사 대표점이며 개별 출입구 위치를 뜻하지 않는다.
