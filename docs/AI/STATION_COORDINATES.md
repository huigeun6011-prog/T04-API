# 대전 1호선 역 좌표

## 출처와 기준

- 기준일: 2026-11-18
- 좌표계: WGS84 (위도, 경도)
- 좌표 출처: 사용자가 지도에서 확인해 전달한 역별 좌표
- `web/app.js`의 `STATIONS`가 지도 마커, 출발지 역 선택, 가장 가까운 역 탐색, 도보 거리 계산에 공통으로 쓰인다. `prediction_api.py`도 이 배열을 읽어 추천 후보의 역 좌표로 사용한다.
- 과거 VWorld 검색 좌표는 사용자가 지정한 좌표로 대체했다. 역 순서와 `idx`는 예측 모델의 역 인덱스에 맞춰 유지한다.
- 지도 선로는 OpenStreetMap 양방향 경로를 바탕으로 하며, 각 역 사이 곡선의 좌표를 역점 좌표 차이에 따라 구간별로 부드럽게 보정해 역 표식에 연결한다.

## 검토 메모

`web/app.js`의 `STATIONS` 22개 값은 이 표와 일치해야 한다. 좌표는 사용자가 지도에서 짚어 준 역 위치이며, 개별 출입구 위치를 뜻하지 않는다. 서버는 앱 소스에서 좌표를 읽으므로 서버 프로세스를 다시 시작해야 새 값이 API 계산에도 반영된다.
