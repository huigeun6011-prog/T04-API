# 공원 출처

- 배포처: 공공데이터포털 연계 대전광역시 API
- 데이터셋: 대전광역시 공원 정보
- API: https://apis.data.go.kr/6300000/parkInfoDaejeonService/parkInfoDaejeonList
- 수집일: 2026-11-16 (Asia/Seoul), 1회 호출
- 원본: `raw/park.xml` (412개 항목; 서버가 XML 응답을 반환)
- 처리: 원본에서 위도·경도 필드를 가져와 CSV로 변환했다. 원본 XML은 응답 형식 그대로 보관했다.
- 라이선스: 연결된 서비스의 상세 이용허락 범위를 별도로 확인하지 못함.
