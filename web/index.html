열차 안의 한산함을 어떻게 예측하나요?

역별 승하차 집계와 열차 시간표로 추정한 재차인원을 바탕으로 이동 구간을 비교합니다. 장소 자체의 혼잡도와 영업시간은 알 수 없습니다.

1단계

재차인원 라벨 추정

승하차 총계와 열차 시간표를 결합하고 출발 전·종점 도착 후 인원과 음수 방지 등의 제약을 적용해 열차별 재차인원을 추정합니다.

→
2단계

조건별 재차인원 예측

HistGradientBoosting 모델이 역·시간·방향·평일/휴일·날씨·시간표 버전을 입력받아 예상 재차인원을 출력합니다. 예측 정확도는 학습 자료와 평가 범위에 따라 달라집니다.

→
3단계

시간·역·장소 추천

Python 예측 서비스가 실제 운행 시간표에서 이동 가능한 후보를 계산합니다. 선택 시간 안에서 이동 구간의 한산함과 직선거리의 비중을 합쳐 순위를 매깁니다.

자정을 넘는 운행

방문 날짜의 24시는 다음 날 00시입니다. 막차의 재차인원은 전날 운행일과 연결하고, 날씨는 실제 시각을 사용합니다. 출발지와 목적지에 같은 역이 연결되면 열차를 타지 않는 후보로 구분합니다.

자세한 수식과 방법은 저장소의 docs/AI/METHODOLOGY.md, 열차 궤적 추출기 사용법은 docs/AI/EXTRACT_TRAIN_LOADS.md 에 정리되어 있습니다.
