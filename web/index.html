어떻게 "한적함"을 예측하나요?

대전 도시철도 1호선에는 열차 내 센서 실측 데이터가 없습니다.
그래서 물리 보존 법칙과 머신러닝으로 직접 만들었습니다.

⚙️
1단계

물리 제약 수치 최적화

개찰구의 역별 승하차 카운트를 바탕으로, 출발역 잔류 0 · 종점 잔류 0 · 재차인원 ≥ 0의 물리 보존 법칙을 손실함수로 삼아 PyTorch Adam Optimizer로 열차별 탑승 인원을 역산 복원합니다.

𝓛 = 𝓛종점오차 + 1.0 × 𝓛음수방지 + 2.0 × 𝓛지리사전
✅ 완료
→
🌳
2단계

GBDT 머신러닝 예측 모델

복원된 정답 데이터로 HistGradientBoostingRegressor(의사결정 나무 앙상블)를 학습합니다.
입력: 역, 시간, 방향, 주말 여부, 기온/강수/적설.

MAE 25.6명 R² 0.84 추론 0.05초/일
✅ 완료
→
🌐
3단계

브라우저 실시간 추론

Python 모델을 ONNX Runtime Web 포맷으로 변환해 별도 서버 없이 사용자 브라우저에서 직접 추론합니다. 모델 ~1MB, 추론 ~1ms, 서버 비용 0원.
