이 문서의 기준·분석 일자는 2026-11-18 당시 설정이다. 사용자가 이후 고정 불필요로 정함(분석 일자·규칙 고정은 필수가 아니며 필요하면 바꿔도 된다. 이미 낸 1/08 결과는 사실로 유지).

## 1/08 환승 관문 재평가

기존 브리프 7절의 1단계는 B↔C 통행의 ±5분 비율 60% 이상, B0의 59.86% 대비 하락 3%p 이하, A↔C 통행의 ±5분 비율 80% 이상을 요구한다. 이 수치와 전체 통행 분모를 유지한다. 기존 B10–C51 및 A77–C46 계산은 재실행 기준으로 사용하지 않는다. 특히 77번 江锦路는 46번 钱江路와 연결되는 A측 선로의 인접역이다.

1. `station_poi_data.csv`의 노선 소속과 1/08 역별 태그 코드를 겹쳐 A/B/C 대응을 구한다. 관측 태그에서의 소속과 POI의 복수 소속을 모두 유지한다. 따라서 5·15는 A와 B, 46은 A와 C에 속한다. 54는 태그가 없어도 C의 물리 그래프에 유지한다. 방향과 종점은 역 ID 정렬 대신 행렬의 노선별 간선에서 도출한다.
2. `Metro_roadMap.csv`의 같은 노선 소속 ID를 잇는 간선을 선로로 사용한다. 같은 ID를 공유한 경우 해당 노선 상태 사이에 환승을 허용한다. 10·51처럼 역명이 같고 ID가 다른 경우 두 노선 상태 사이에 환승을 허용한다. 행렬에서 양쪽의 이웃에 중복 연결된 간선은 이 환승으로 설명한다. 태그 행의 `lineID`는 개찰구가 부여한 분류이며, 공유역의 실제 승차·하차 노선은 가능한 복수 소속에 모두 열어 둔다.
3. 같은 사용자 ID의 바로 앞 태그가 입장이고 시차가 0분 초과, 180분 이내인 출장을 짝지어 평가한다. 같은 초에 두 태그가 있으면 출장 태그를 먼저 정렬한다. 기존 방식과 같이 `payType` 전체를 포함한다. 헤더와 행렬 유효성을 검사하고, 원본 1/08 파일에서 다시 계산한다.
4. 양 끝이 각각 하나의 물리 노선에만 속하는 동선 통행으로 노선별 운행시간 근사치를 적합한다. 물리 간선 수별 25분위수(30건 이상)를 누적 최댓값으로 단조화한다. 1~8간선 구간의 선형 추세에서 얻은 절편을 빼고 0 이상으로 자른다. 관측 범위 밖에는 같은 적합의 양의 기울기를 사용한다. 0간선 구간의 운행시간은 0이다.
5. 노선을 되돌아타지 않는 0~2회 환승 후보에서 노선별 운행시간 근사치의 합에 환승당 5분을 더해 가장 낮은 경로를 선택한다. 동률이면 환승이 적은 쪽을, 이후에는 노선과 간선의 정렬 순서를 따른다. 5분은 모든 역에 공통인 경로 선택 가정이다. 통행별 실제 소요시간은 후보 선택에 사용하지 않는다. B↔C와 A↔C 그룹별 실제 통행시간에서 선택 경로의 점수를 뺀 잔차의 중앙값을 보정 상수 `W`로 사용하고, 보정 후 절대잔차가 5분 이내인 비율을 센다. 양방향을 통합하며 같은 날 적합과 평가는 내부 일관성 점검이다.
6. 이 관문은 교차노선 추정의 품질을 평가한다. 사용자의 범위 정리에 따라 C 직접 통행에서 방향을 얻어 만드는 시간표의 선행 조건으로 사용하지 않는다. 교차노선 경로는 보조 결과로 따로 남긴다. 신규 실행의 유일한 일별 원본은 `record_2019-01-08.csv`다. 기존 `scan_days.py` 및 `day_scan.csv`에는 1/15 원시 파일을 읽어 집계한 이력이 있다. 해당 집계를 이번 계산이나 설정에 사용하지 않는다.

## C 전용 방향 관문과 피크 관문

입장과 출장이 서로 다른 C 태그 역에서 이루어진 직접 통행을 방향 앵커로 사용한다. 두 역을 C 선로상의 위치로 놓고 순서대로 `toward_66`과 `toward_34`로 구분한다. C46을 포함한 통행을 직접 통행 후보로 쓰면서 공유역 관련 개수를 보고하고, 제외한 비율도 진단용으로만 기록한다. 이용자가 실제 이동 중 환승했는지는 태그에 없다. 가상의 하차는 추가하지 않는다.

C 태그 하차 전체 중 직접 방향 부여 비율은 60% 이상이어야 한다. 10~16시의 C 태그 하차를 분모로 하여 방향을 얻은 태그 중 `stageA_peaks.py`의 `clear` 역·방향에 속한 하차가 전체의 60% 이상이어야 한다. 방향 미지정 하차는 방향별 검출 범위에 기여하지 않는다. 하나라도 실패하면 조각화 단계 전에 중단한다.

관문 통과 후에는 방향별 1초 히스토그램을 σ 10초로 평활한다. 같은 방향에서 45초 이상 떨어지며, 평활 높이가 해당 시각 전후 30분 평균의 2.5배 이상인 피크를 사용한다. 피크가 자기 prominence의 절반을 넘는 왼쪽 시각을 태그 유입 기준으로 삼고, 공통 도보 지연 30초를 빼 도착 후보 시각을 얻는다. 30초는 절대 시각을 내기 위한 분석 가정으로 역별 실제 보행시간의 차이는 남는다. 피크를 앞뒤 관측으로 확인한 연결에 우선 쓰되, 관문의 일부로 단독 피크도 분모에 남긴다.

## 열차 연결과 조각화 지표

구간시간 초깃값은 직접 통행을 같은 방향과 같은 OD로 모아 30건 이상인 통행의 소요시간 Q25를 계산하고, 공통 접근시간 상수(0초 이상)와 노선의 구간시간 합(관측역 간 최소 30초)으로 가중 최소제곱 적합한다. 가중치는 OD 통행 수다. 초깃값의 ±120초 내에서 같은 방향의 이웃 역 피크를 순서 보존 1:1 매칭하고, 매칭된 시간차의 중앙값을 다음 단계에 사용한다. 표본이 없으면 초깃값을 유지한다. 최종 매칭의 허용 오차는 ±45초다.

매칭은 허용 창 내 연결 수를 최대로 한 뒤 절대 시간잔차 합을 최소화한다. 먼저 연속 관측역을 잇고, 연결되지 않은 끝점에 한해 1역 누락, 2역 누락 순서로 연결한다. 누락역이 있는 연결에도 전체 시간차의 오차 ±45초를 적용한다. 앞뒤 관측이 있는 역만 구간시간 비율로 보간하고, 기존 연결을 추월하는 후보는 거른다. 54번은 선로 연결 시간을 유지하되 도착 이벤트로 발행하지 않는다. 1/08 경계 밖으로 이동한 후보 시각은 제외하고 수를 기록한다.

D단계의 분모에는 연결된 열차 후보와 역 하나로 남은 피크를 모두 포함한다. 관측 피크에서 시작·끝난 위치가 양쪽 종점에서 각각 2역 이내인 열차 비율은 60% 이상, 관측 역 수가 1~2개인 열차 비율은 5% 이하여야 한다. 방향별 표와 양방향을 합친 표에서 아래 지표를 산출한다.

- 열차별 관측 역 수, 보간 역 수, 연결된 역 수, 처음·마지막 역 ID, 양 끝의 종점까지 거리
- 관측 역 수와 연결된 역 수의 전체 분포, 1~2역 조각 비율, 시작과 마지막 역의 전체 분포
- 종점 2역 이내 출발·도착 비율 각각과 양쪽 동시 비율, 중간역 출발·종착 비율 각각
- 보간 도착 이벤트 수를 총 도착 이벤트 수로 나눈 비율 및 역별 보간 비율

연속역만 직접 연결한 기준, 1~2역 누락을 건너 연결한 경로의 관측 피크 기준, 같은 경로의 보간 도착 포함 기준을 각각 보고한다. 통과 여부는 가운데 관측 피크 기준을 양방향 통합해 평가한다. 태그 피크 기반의 중간역 시작·종착에는 관측 누락과 실제 회차가 섞일 수 있다. 54번은 선로 그래프에 존재하나 이 자료로 영업 정차를 확인할 수 없다. 해당 위치를 지난 추정만으로 도착 이벤트를 발행할 수 없다. 역 내 도보시간 추정에 따라 절대 도착시각은 불확실하며 `observed`는 직접 열차 측정이 있는 값이 아니라 태그 피크에 근거한 추정을 뜻한다. D가 실패하면 후보 이벤트를 진단 파일로만 표시하고 시간표와 1/15 적용은 중단한다.
